# Эстетика — демо-концепт

Статический сайт без фреймворков и npm-зависимостей. Для просмотра откройте `index.html` в браузере. Для сборки нужен Node.js 18 или новее:

```sh
npm run build
```

Готовые файлы находятся в `dist/`. Можно размещать на любом статическом хостинге. `_headers` задаёт дополнительные заголовки на поддерживающих его площадках (например, Netlify). На остальных хостингах настройте `X-Robots-Tag: noindex, nofollow, noarchive` самостоятельно. Meta robots и robots.txt включены независимо от хостинга; это не ограничение доступа, для приватного просмотра нужна авторизация на сервере.

Визуальное направление — редакционная медицинская эстетика в духе Grove: белый фон, зелёный акцент #0b835c, серые карточки #eff1f6 и тёмные кнопки-пилюли. Шрифты Inter и Lora (с кириллицей) подключены через Google Fonts; без сети используются Arial и Georgia. На первом экране — информационная карточка с реальными контактами, без стоковых врачей, имитации чата или онлайн-записи. Абстрактные иллюстрации в интерфейсе не используются. Сайт не собирает заявки и не хранит персональные данные; запись — звонком в клинику.

## Источники данных

- Название, адрес, телефон, ссылка на VK и тексты отзывов: https://estetika-ulitsa-rovio.clients.site/ (проверено 25.10.2026).
- Часы работы: `local businesses.md`.
- Отзывы изложены пересказом, без имён авторов. Первые две карточки — разные аспекты одного исходного отзыва, что отмечено в подписи.
- Цены, перечень услуг, врачи, лицензия, оборудование и гарантии не добавлены: подтверждённых материалов нет.

На странице постоянно присутствует маркировка демо. Перед официальной публикацией необходимо согласовать содержание с клиникой, проверить актуальность контактов, получить юридические сведения и документы.
